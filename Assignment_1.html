Instructions

1 · Document & Layer Setup

Start every drawing the same way — correct template, correct layers — so precision work later isn't undone by a setup mistake.

Document Setup

  • Template: Architectural Imperial.dwt (or standard Imperial units)
  • Work directly in Model Space

Guides Layer

  • Color Index 253 (Dark Gray)
  • Purpose: bounding boxes that enclose each letter

Letters Layer

  • Color: Cyan
  • Purpose: letter linework and hatch application

2 · Guiding Boxes (Guides Layer)

Drawing Specifications

  • Dimensions: each letter is inscribed within a guiding box measuring 24" wide × 36" high (2′ × 3′)
  • Spacing: guiding boxes spaced exactly 6" apart horizontally
  • Polyline standard: draw each box as a continuous closed polyline (PL, closed with C)
  • First box origin: start the first box at (0,0)

3 · Letter Drafting (Letters Layer)

  • Tool restriction: draw all letters using polylines (PLINE) only — no standard lines, arcs, or text objects
  • Closed polylines: every letter boundary or segment must form a fully closed polyline using the Close (C) option
  • Arcs in polylines: for rounded letters (e.g., 'D'), use the Arc (A) sub-command within PLINE with second-point positioning (S), then switch back to Line (L) to close
  • Object snaps: use Endpoint, Midpoint, and Mid Between 2 Points (Shift + Right Click) to snap letter geometry precisely to the guiding boxes

4 · Hatching (Letters Layer)

Apply solid or patterned hatches (HATCH / H) to all letters, demonstrating two distinct hatch behaviors:

Individual (Separated) Hatches

  • Hatch at least three letters together
  • Use Separate Hatches in the Hatch Editor to modify scale, angle, and pattern independently for each

Grouped Hatches

  • Apply a single hatch pattern across a group of remaining letters
  • Do not separate them — they share identical properties as one object

Submission Criteria

0 / 3 complete

Evaluation Rubric

Total possible score: 100 points across 3 criteria.

1. Layer & Template Setup (25 pts)

Excellent
21–25 pts

Uses Architectural Imperial template. Guides and Letters layers are correctly set up and used. The first guide box starts precisely at (0,0), and all geometry is on the correct layer.

Proficient
11–20 pts

Layers are created and used, but minor errors exist (e.g., incorrect color choice, slight origin offset, or a few elements placed on the wrong layer).

Developing
0–10 pts

Layers are missing, wrong template was used, or objects are left on Layer 0.

2. Geometry Precision & Closed Polylines (45 pts)

Excellent
37–45 pts

All guide boxes are exactly 24" × 36" with 6" spacing. Every letter and box is drawn exclusively with polylines and verified as closed. Object snaps are used accurately.

Proficient
21–36 pts

Dimensions and spacing are accurate, but some polylines are open, or standard LINE/ARC tools were used instead of polyline sub-commands.

Developing
0–20 pts

Inaccurate box dimensions or spacing, widespread unclosed lines, or misuse of basic drafting tools.

3. Hatching Execution & Properties (30 pts)

Excellent
25–30 pts

All letters are hatched on the Letters layer. Correctly demonstrates both Individual (Separated) hatches with custom scale/angles and Grouped hatches sharing properties across multiple letters.

Proficient
13–24 pts

Hatching is applied to all letters, but fails to differentiate between separated and grouped hatches, or properties are left at default settings.

Developing
0–12 pts

Hatching is incomplete, missing, or applied outside closed boundaries or on the wrong layer.
