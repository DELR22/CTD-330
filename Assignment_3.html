Assignment 3 of 8 · Custom Geometry

Build a custom geometric floor plan and organize it with layer groups.

Rather than tracing a predefined model step-by-step, as showcased in the 045T-Layers Test tutorial video, you will construct a dynamic geometric plan from base shapes, manage project organization through organized layer groups, insert dynamic block components, and adjust linetype scales and hatch patterns.

Part 1 · Template & Layer Setup

  1. Start a new drawing using the Architectural Imperial template (Architectural Imperial.dwt)
  2. Switch to Model Space
  3. Open Layer Properties Manager (LAYER) and configure all layers listed above
  4. Create two new Layer Filters (Groups): INTERIOR (I-WALL, I-DOORS, I-WINDOWS, I-FIXTURES) and GENERAL (_PROJECTION LINES, _LINE TYPES)

Part 2 · Reference Key & Linetype Testing Board

  1. On layer _LINE TYPES, use PLINE to draw a horizontal reference line starting at origin 0,0 with a length of 24"
  2. Move (MOVE) the line 36" to the right to create your workspace key
  3. Using OFFSET, create 5 parallel copies spaced 12" apart vertically
  4. Assign the lines sequentially to represent each layer in your drawing (I-WALL, I-DOORS, I-WINDOWS, _PROJECTION LINES, _LINE TYPES)
  5. Use MTEXT with Arial font, 2" height, to label each line. Use MATCHPROP to match text color to its corresponding layer

Linetype Test Board

  • Load additional linetypes (LINETYPE): ZIGZAG, DASHDOT, and DOT
  • Draw three sample lines on layer _LINE TYPES and assign one of the new linetypes to each
  • Select a line, open the Properties Palette (PR), and adjust its Linetype Scale (e.g., 2.0 or 4.0) to demonstrate scale visibility control

Part 3 · Geometric Floor Plan Construction

Note: create your own unique floor plan layout following the geometric parameters below.
  1. Set I-WALL as the current layer
  2. Use the Polygon tool to construct a regular polygon with at least 5 sides (e.g., Heptagon = 7, Octagon = 8) set to an inscribed radius between 6'-0" and 8'-0"
  3. Copy the polygon twice (3 total), overlapping them by snapping from one vertex to the midpoint of each shape (Shift + Right-Click → Mid Between 2 Points) to create a complex, intersecting footprint
  4. Draw an enclosing rectangle around the overlapping polygons
  5. Use BOUNDARY to generate a single closed outer perimeter polyline of the combined space. Move the new boundary shell away from the construction geometry
  6. Offset the boundary polyline 5" inward to establish thick exterior structural walls
  7. Use Polyline and Offset to create openings for doors and windows across non-orthogonal wall faces. Trim unnecessary wall segments
  8. Join remaining wall segments using Polyline Edit into single polyline elements

Part 4 · Component Insertion & Non-Orthogonal Alignment

  1. Open Tool Palettes
  2. Set active layer to I-DOORS and drag an Imperial Door block into model space
  3. Use the ALIGN command to attach the door to an angled wall segment, adjust swing direction, set swing angle to 90°
  4. Set active layer to I-WINDOWS and insert an Imperial Window block. Align it into an angled wall opening and draw windowsill lines as single-segment polylines
  5. Set active layer to _PROJECTION LINES and draw a dashed polyline indicating the doorway threshold as an overhead projection. Adjust its linetype scale in Properties if needed

Part 5 · Fixtures and Hatching

  1. Set active layer to I-FIXTURES
  2. Insert architectural fixtures (e.g., Toilet, Sink, or custom furniture shapes built with simple Circles and Rectangles)
  3. Set active layer to I-WALL
  4. Apply Wall Hatch: color 251 (Medium Gray), pick the polylines that make the walls
  5. Apply Interior Pattern Hatching on I-FIXTURES or floor regions using custom linetype variations or pattern fills across internal boundary intersections

Evaluation Rubric

Total possible score: 300 points across 3 criteria.

1. Layer Architecture & CAD Standards (90 pts)

Excellent
81–90 pts

Layers are precisely created with correct naming, colors, linetypes, and lineweights. Layer filters (INTERIOR and GENERAL) are fully populated.

Proficient
63–80 pts

Layers are present with minor errors in naming, color assignment, or lineweight settings. Layer filters are created but have minor sorting errors.

Developing
0–62 pts

Multiple required layers, filters, or properties are missing or misconfigured.

2. Geometric Execution & Boundary Shell (120 pts)

Excellent
108–120 pts

Base geometry uses a regular polygon with required geometric variables. A single closed outer perimeter shell is created, offset by 5". Wall openings are precisely trimmed with all intersections joined.

Proficient
84–107 pts

Base polygon construction and snaps are generally accurate with minor alignment errors. Boundary shell is generated and offset by 5", but contains minor geometry overlap or unjoined segments. Door/window openings are trimmed but show minor gaps or unjoined wall lines.

Developing
0–83 pts

Polygon has fewer than required sides or incorrect radius. Failed to generate a clean closed perimeter. Wall offset is missing or inconsistent. Wall openings are incorrectly trimmed, leaving stray lines, gaps, or overlapping geometry.

3. Component Integration, Alignment & Hatching (90 pts)

Excellent
81–90 pts

Door and window blocks on corresponding layers are accurately aligned along non-orthogonal wall faces without distortion. Doorway threshold projections are clearly visible. Fixtures are well-placed. Solid hatch and interior pattern hatches cleanly fill boundaries without leaking.

Proficient
63–80 pts

Blocks are inserted on correct layers but show minor alignment or scaling issues along angled walls. Fixtures are present, but placement is loose. Solid wall hatch or pattern hatching is applied, but displays minor boundary leaks or scale misalignments.

Developing
0–62 pts

Blocks are placed on incorrect layers or display visible misalignment along angled walls. Door projections are missing. Fixtures are omitted. Wall hatch or pattern hatching is missing, incomplete, or leaking due to unclosed boundaries.
