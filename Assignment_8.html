Step 1 · Prepare & Clean the Floor Plan X-Ref File

Before sharing or referencing a floor plan, ensure the drawing is "clean" to avoid carrying unnecessary layers, blocks, or orphan objects into downstream project files.

1.1 Purge Unused Elements
  1. Open your completed Floor Plan (from Assignments 5 & 6) in AutoCAD
  2. Type the command PURGE and press Enter
  3. In the Purge dialog box, review items listed under Named Items Not Used (unused blocks, layers, text styles, dimension styles)
  4. Uncheck any specific styles you intend to preserve for later use if necessary
  5. Click Purge Checked Items (or Purge All) and confirm by selecting all checked items
  6. Verify that no sub-lists remain under unused categories
1.2 Verify Origin & Clean Model Space Boundary
  1. Ensure no distant "orphan" objects or stray points exist in Model Space: double-click your mouse scroll wheel (or use ZOOM > Extents) — if the floor plan shrinks significantly, stray objects exist outside your workspace
  2. If tiny points remain hard to see, type REGEN to regenerate the display; locate, select, and ERASE all stray objects
  3. Set or confirm your base origin point (0,0,0) using COPYBASE (Ctrl+Shift+C): select a known reference corner of your building/grid as the base point
  4. Open a clean drawing, paste using PASTECLIP (Ctrl+V), and locate it to a previously defined coordinate
  5. Clear out the interior of the common areas on the floor plan, leaving empty spaces ready for layout development while preserving structural walls, columns, perimeter enclosures, and room core layouts
  6. Save this file as FloorPlan_XRef.dwg and close it

Step 2 · Set Up the Main Project Drawing File

2.1 File Initialization
  1. Open AutoCAD and start a new file using the course template (2026_UA ID CAD Template.dwt)
  2. Confirm that all standard layers, text styles, dimension styles, and annotation blocks are loaded from the template
  3. Save the new drawing immediately as LastName_FirstName_A08.dwg
2.2 Attach the Floor Plan X-Ref
  1. Type XREF and press Enter to open the File References palette
  2. Click the drop-down menu in the top-left of the palette and select Attach DWG…
  3. Browse and select your cleaned FloorPlan_XRef.dwg file
  4. In the Attach External Reference dialog box, set: Reference Type = Overlay (prevents nested X-Refs); Path Type = Relative Path; Insertion Point = X,Y,Z = 0 (uncheck Specify On-Screen); Scale = X,Y,Z = 1.0 (uncheck Specify On-Screen, maintains 1:1 true scale); Rotation = 0°
  5. Click OK
  6. Verify alignment — the floor plan should instantly snap into model space at the predefined coordinates

Step 3 · Develop Common Areas

Wall & Enclosure Development

  • Enclose stair shafts using standard 6″ interior wall layers (A-WALL)
  • Apply solid, wipe-out hatching (color 255,255,255)
  • Place standard 36″ or 42″ doors where required

Stair Placement

  • Insert/align, as blocks, the single-tread stair (1_Tread_Stair) in Common Area 1
  • Double-tread stair (Double_Tread_Stair) in Common Area 2
  • Minimum clearance path of 48″ around all stair accesses

Furnishing & Spatial Layout

  • Insert furniture blocks (lounges, sofas, reception desks, tables) from the template block library to furnish adjacent common/lounge spaces

Step 4 · Layout, Scale, and PDF Plotting

  1. Switch to a Paper Space Layout tab (8.5″×11″ or 11″×17″) within the class template
  2. Double-click inside the Viewport to enter Model Space
  3. Set the Viewport Scale precisely to 1/8″ = 1'-0″ from the status bar scale menu
  4. Ensure title block attributes (Student Name, Date, Scale, Assignment 8) are accurately populated
  5. Execute PLOT / EXPORTPDF to generate the final PDF deliverable

Deliverables

Evaluation Rubric

Total possible score: 500 points across 3 criteria.

1. X-Ref Preparation & Insertion Accuracy (225 pts)

Excellent
150–225 pts

The X-Ref file is completely purged of all unused elements, with zero stray model space objects. Attached as a Relative Path, Overlay, perfectly aligned at origin coordinates at a true 1:1 scale without nested drawing errors.

Proficient
75–149 pts

The X-Ref is attached as an Overlay and aligned at origin coordinates. Minor unpurged elements or non-critical orphan objects remain in the base file, or Path Type was set as absolute rather than relative.

Developing
0–74 pts

X-Ref is incorrectly attached as an Attachment (causing potential nesting), misaligned from origin coordinates (0,0,0), scaled incorrectly, or the base file contains substantial stray objects that distort the drawing bounds.

2. Spatial Development & Drafting Compliance (175 pts)

Excellent
117–175 pts

Enclosures utilize accurate wall thickness, door, and window measurements with solid white hatch overlays (255,255,255). Stair blocks are correctly assigned with all clearance paths exceeding the width of the stairs. Common spaces are thoughtfully furnished using template blocks.

Proficient
58–116 pts

Walls, doors, and stair blocks are present and assigned to appropriate layers. Hatching is applied, though minor errors exist in clearance dimensions or furniture layout shows minor spatial conflicts.

Developing
0–57 pts

Missing wall layers/hatching, incorrect door sizing, misplaced stair blocks, or clearance paths fall below required minimums. Furnishings are sparse, misaligned, or unorganized.

3. Layout, Scaling & Output Execution (100 pts)

Excellent
67–100 pts

Paper space layout is properly configured with Viewport scale accurately set. All title block attributes are complete and accurate. PDF and physical printout output is cleanly plotted without visual glitches.

Proficient
34–66 pts

Paper space layout is set with accurate Viewport scale. Minor omissions in title block data or minor visual inconsistencies in the final PDF and physical plot.

Developing
0–33 pts

Viewport scale is incorrect or unscaled, title block attributes are left blank or default, or the PDF/physical deliverable is improperly formatted/missing.
