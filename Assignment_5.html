Deploy a full hotel floor plan using nested blocks and reference editing.

Develop AutoCAD skills using nested blocks, layer filters, reference editing, and polyline management. You will construct a complete Hotel Typical Floor Plan utilizing nested block workflows to easily deploy and modify modular space layouts across a multi-room facility.

Topics & AutoCAD Tools Covered

Polyline Optimization

  • PLINE, PEDIT, CHAMFER — managing closed-loop boundaries for clean hatching, area calculations, geometry editing

Block Definition & Nesting

  • BLOCK, BEDIT, REFEDIT — modular unit blocks containing sub-blocks, edited in-place via Add/Remove from Working Set

Layer Property Filters

  • LAYER — grouping, filtering, organizing by category (Walls, Doors/Windows, Floors, Projections, Annotations)

Advanced Hatching & Draw Order

  • HATCH, DRAWORDER — continuous surface fills, patterns, visual hierarchy

Array, Mirror & Precision

  • MIRROR, COPY, Shift + Right-Click Mid Between 2 Points — rapid deployment across corridors

Spatial Constraints & Layout Configuration

Central Corridor

  • Clear width of 7'-0"
  • Vertical (N–S) or horizontal (E–W) orientation

Total Room Count — 12

  • 8 Standard Rooms — arrayed along the hallway (4 per side)
  • 4 Corner Rooms — at the four corners, distinct facade variation

Two Room Block Types

  • Hotel_Room_Standard — main typical interior unit
  • Hotel_Room_Corner — variation featuring facade updates
Design Distinction: room interior layouts must not copy the single-bed tutorial unit shown in the demonstration videos. Use a distinct layout strategy (e.g., double queen beds, suite divider, or expanded seating area).

Step 1 · Set Up Layer Filters and Structure

  1. Use the Architectural Imperial Template
  2. Open the Layer Properties Manager (LAYER)
  3. Create two new Group Filters: Partitions and Blocks
  4. Set up standard color-coded layers and assign them to the corresponding filters (below)

Step 2 · Build Interior Furniture & Fixture Sub-Blocks

  1. Construct furniture assets on their respective layers using strict polyline boundaries (PLINE)
  2. Define individual sub-blocks (BLOCK or B):
    • Door Blocks: build a 36in_Door block and a 42in_Main_Door block using a 1.5" leaf thickness and an arc swing (ARC → Center, Start, End). Apply solid fill hatching (255,255,255 or ByLayer) to door leaves
    • Bathroom Fixtures: block out standard ADA clearances, shower stalls, vanities, and toilets
    • Living/Bedroom Furniture: create double bed units, nightstands, wardrobes/closets, desk workstations, and TV console units
Note: it's recommended to use the blocks created in Tutorials 046–051 by working in the same file. Otherwise, use Copy with Origin Point: press Ctrl+Shift+C (COPYBASE), select the objects, click your origin/base point, press Enter — then paste into the destination file with Ctrl+V.

Step 3 · Construct Room Type 1 (Hotel_Room_Standard)

  1. Assemble wall partitions using 5" thick closed polyline segments
  2. Position bathroom and main entry doorways, ensuring ADA clearance (minimum 18" pull-side clearance on doors)
  3. Place interior furniture sub-blocks into position
  4. Apply floor finish hatches (HATCH) on layer 03-Floors (tile in bathroom, wood/carpet in living area). Send hatching to back (DRAWORDER → Send to Back)
  5. Select all room elements and define the master block — Name: Hotel_Room_Standard; Base Point: the exterior corner intersection of the main hallway wall

Step 4 · Create Room Type 2 (Hotel_Room_Corner)

  1. Double-click or use REFEDIT / BEDIT on a copy of Hotel_Room_Standard
  2. Use Save Block As (BSAVEAS or Block Editor Options) to create Hotel_Room_Corner
  3. Modify the exterior facade geometry (e.g., add a corner window or balcony); adjust wall polyline boundaries using PEDIT → Add Vertex and TRIM/CHAMFER
  4. Re-hatch modified wall sections and update floor finish boundaries

Step 5 · Floor Plan Assembly & Corridor Deployment

  1. Draw two parallel reference lines on 01-Walls spaced 7'-0" apart to define the central corridor
  2. Place the first Hotel_Room_Standard block along the top corridor wall
  3. Mirror (MIRROR) the room across the corridor centerline using Shift + Right-Click → Mid Between 2 Points between top and bottom hallway lines
  4. Copy (COPY) the room pair across the length of the corridor until 4 rooms line each side (8 standard rooms total)
  5. Insert Hotel_Room_Corner blocks at the 4 outer ends of the floor plan
  6. Verify wall alignment and shared partition boundaries

Step 6 · In-Place Block Refinement (REFEDIT)

  1. Select any standard room block, right-click, and select Edit Block In-Place (REFEDIT)
  2. Add corridor wall hatching across all shared wall segments
  3. Use Add to Working Set / Remove from Working Set toolbars to incorporate shared boundary lines into the main block definition
  4. Save changes (REFCLOSE → Save). Observe all identical room instances updating across the floor plan
