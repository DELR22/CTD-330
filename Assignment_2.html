2 · Room Geometry & Connecting Hallway (A-WALL Layer)

First Room

  • Start at origin (0,0) using RECTANGLE (REC)
  • Interior area: 326 Sq. Ft. (convert to square inches)
  • Width: 16' — let AutoCAD auto-calculate the length

Second Room

  • Duplicate or create an identical second room
  • Position 6' apart horizontally from the first room

Hallway

  • Draw a 6' connecting hallway joining the two rooms
  • Clean up intersecting corners with TRIM (TR) and zero-radius CHAMFER (CHA)

Wall Thickness & Consolidation

  • Use OFFSET (O) set to 5" to create continuous 5"-thick walls throughout the entire interior perimeter
  • Join all individual line segments into unified outer and inner wall polylines using PEDIT (PE → Join)

3 · Openings, Doors & Windows

Wall Openings

  • Create rough openings for doors and windows in the wall polylines using TRIM (TR)
  • Cap exposed wall ends using closed polylines/rectangles on A-WALL

Doors (A-DOORS)

  • Open Tool Palettes (PALETTES / TOOLPALETTES) → Architectural tab
  • Insert the dynamic Door - Imperial block into each room's door opening
  • Room 1 Door: width 40"
  • Room 2 Door: a different width (e.g., 36")
  • Adjust wall thickness grip to 5" and flip swing arrows so each door opens inward toward an adjacent wall

Windows (A-WINDOWS)

  • Insert the dynamic Window - Imperial block into each room
  • Set wall thickness to 5" and adjust frame
  • Draw polyline window sill lines across the wall opening

4 · Wall Hatching (A-WALL Layer)

  • Close off wall opening boundaries using polylines or rectangles so wall voids form fully enclosed loops
  • Apply a Solid Hatch (HATCH / H) to all wall interiors
  • Set the hatch color to Index Color 251 (Dark Gray)

Evaluation Rubric

Total possible score: 200 points across 3 criteria.

1. Document Setup, Layers & Hatching (50 pts)

Excellent
43–50 pts

Drawing is created in Architectural Imperial.dwt. Layers are correctly configured with designated colors. All solid hatching is applied to cut walls within closed boundaries.

Proficient
26–42 pts

Template and required layers are used, but minor errors exist (e.g., incorrect layer color, slight misalignment of hatched areas, or minor elements placed on incorrect layers).

Developing
0–25 pts

Missing layers, incorrect template used, hatching is missing/leaking outside walls, and objects remain on Layer 0.

2. Wall Geometry, Area Precision & Polylines (90 pts)

Excellent
76–90 pts

Both rooms accurately achieve 326 Sq. Ft. interior area with a 16' width. The connecting hallway is exactly 6' wide. All walls are precisely 5" thick and consolidated into continuous, closed polylines.

Proficient
46–75 pts

Room areas and hallway dimensions are close to specification, but minor precision errors exist (e.g., small dimension inaccuracies, wall thickness variance, or unjoined wall polylines).

Developing
0–45 pts

Significant dimensional errors, incorrect room square footage, improper wall thickness, or unmanaged individual line segments throughout.

3. Openings, Doors & Windows (60 pts)

Excellent
51–60 pts

Door and window blocks are properly inserted from the Tool Palette with a 5" wall thickness setting. Doors have two different widths and swing inward toward adjacent walls. Windows are placed on the corresponding layer with properly capped openings and window sill polylines.

Proficient
31–50 pts

Doors and windows are placed, but exhibit minor issues (e.g., door widths are identical, swing directions are flipped incorrectly, or window sill linework is omitted).

Developing
0–30 pts

Missing doors or windows, block misuse, uncapped wall openings, or objects placed on incorrect layers.
