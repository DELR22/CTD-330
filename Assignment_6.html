Technical Objectives

  1. Translate model-space designs from Assignment 5 into paper-space layouts using accurate architectural viewport scaling
  2. Maintain standard layer hierarchies, line weights, and plot style table (.ctb) controls across all sheets
  3. Manage varying sheet scales (1/8″=1′-0″, 1/4″=1′-0″, 1/2″=1′-0″) using appropriate sheet size selection (8.5″×11″ or 11″×17″)
  4. Configure Title Blocks with clear drawing information (Project Title, Sheet Name, Scale, Date, Author, Sheet Number)
  5. Master vector PDF exports and high-resolution physical plot configurations

Step 1 · Layout & Title Block Setup

  1. Switch to Paper Space (Layout Tab) for each sheet
  2. Open Page Setup Manager (PAGESETUP); create or modify layout setups — Printer: DWG To PDF.pc3; Paper Size: ANSI A (8.5″×11″) or ANSI B (11″×17″); Plot Area: Layout; Plot Scale: 1:1; Plot Style Table: Monochrome or designated project CTB file
  3. Insert or draw your standard Title Block on layer, with fields for Drawing Title (e.g., HOTEL FLOOR PLAN), Sheet Scale, Date, Student Name, Course Info, and Sheet Number (A-101, A-501, etc.)

Step 2 · Viewport Creation & Exact Scaling

  1. Create viewports using MVIEW on the viewport layer (set this layer to non-plotting in the Layer Properties Manager)
  2. Activate the viewport (double-click inside) and center the target plan area
  3. Set the precise Viewport Scale via the Status Bar — Sheet 1: 1/8″=1′-0″; Sheet 2: 1/4″=1′-0″ (isolate Standard and Corner rooms); Sheet 3: 1/2″=1′-0″ (isolate Enlarged Bathroom Plan)

Step 3 · Export & Physical Plotting

  1. Export each layout tab to vector PDF using the PLOT or EXPORTPDF command
  2. Verify exported PDFs in Adobe Acrobat or equivalent: confirm lineweights display correctly (no grey/faded CAD default colors unless intended), and title block information is legible and aligned
  3. Send PDFs to a physical printer
Set printing options to Actual Size (100% scale) — do not select "Fit to Printable Area," as this alters the physical scale of the drawing.
