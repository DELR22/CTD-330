Assignment 4 of 8 · Block Design

Design nine original furniture and appliance blocks, complete with a sticker hatch.

Research, design, and model custom architectural furniture and appliance blocks in AutoCAD. Instead of copying reference files directly, you will design original components inspired by real-world commercial furniture and appliances — incorporating functional ergonomics, correct standard clearance zones, and appropriate level-of-detail (LOD) linework.

1 · Architectural Drafting & Layer Management

  • Create dedicated, well-named layers for each fixture or furniture category before drafting (e.g., 02-Kitchen, 02-Laundry, 02-LivingRoom)
  • Draw using polylines to establish clean, closed boundaries for hatch assignments and easy vertex modifications
  • Leverage Object Snap Overrides / Point Filters to anchor geometry precisely
KeyCommandUse
PLPolylineClosed outer boundaries
CCircleDrains, rounded tables, accents
HHatchSolid fill, Color 255,255,255
BBlockBlock Creation Definition
PURGEPurgeRemove unused or duplicate block definitions from file memory

2 · Ergonomics & Clearance Zones

  • Design all items according to real-world commercial dimensions and accessibility guidelines
  • Indicate required functional clearance zones using dashed polylines

3 · Solid 255 "Sticker" Hatch Integration

Every block must feature a solid 255 hatch "sticker" background that hides underlying floor plans or tile patterns without destroying or trimming hatch lines underneath.

  1. Apply a solid hatch using Color 255,255,255 to the inner boundary of the object
  2. Adjust object display order (Right-click → Draw Order → Send to Back / Bring to Front) so the solid hatch stays behind the linework
  3. Include both the geometry and the solid 255 hatch when defining the block (B)

Required CAD Blocks to Design

Group A · Kitchen Appliances & Fixtures

  • Refrigerator — minimum footprint with door swing arc/clearance paths
  • Stove — standard cooktop profile including burner elements
  • Kitchen Sink — single or double basin sink with faucet and drain
  • Dishwasher — standard under-counter footprint with DW convention (tag)

Group B · Laundry Room

  • Washing Machine — top-load or front-load unit
  • Clothes Dryer — matching unit paired with the washer

Group C · Living Room Furniture (choose 3 unique pieces)

  • Piece 1 (e.g., Sofa / Sectional) — base with ergonomic seat depth
  • Piece 2 (e.g., Coffee / Side Table) — square, rectangular, or round geometry matched to seating proportions
  • Piece 3 (e.g., Media Console, Accent Chair, or Bookshelf) — proportionate functional depth and line accents

Evaluation Rubric

Total possible score: 300 points across 3 criteria.

1. Polyline Geometry & Layer Organization (100 pts)

Excellent
90–100 pts

All blocks are built from clean, closed polyline boundaries with accurate origin placement. Each furniture/appliance category is drafted on its own dedicated, well-named layer.

Proficient
70–89 pts

Most blocks use closed polyline geometry with only minor origin inaccuracies; layers are present, but a few objects are misassigned, or layer naming is inconsistent.

Developing
0–69 pts

Geometry has unclosed polylines, standard lines, or unconnected segments; objects are left on Layer 0 or lack dedicated category layers.

2. Ergonomic Accuracy & Level of Detail (100 pts)

Excellent
90–100 pts

Every block reflects real-world commercial dimensions and accessibility guidelines, with required clearance/access zones drawn as dashed polylines. Linework is limited to essential geometry — no unnecessary ornamental detail beyond general form and ergonomic variables.

Proficient
70–89 pts

Dimensions are generally realistic and most blocks include clearance zones, but a few are inaccurate, missing, or drawn with an inconsistent line type; level of detail is slightly under- or over-drawn on some pieces.

Developing
0–69 pts

Dimensions do not reflect real-world standards, clearance zones are missing or incorrectly drawn, or blocks contain excessive unnecessary detail unrelated to general geometry and ergonomics.

3. Block Definition, Base Points & Reference Sheet (100 pts)

Excellent
90–100 pts

All blocks are properly defined, each with a logically placed Insertion Base Point, and the file is purged of unused/duplicate block definitions. The Inspiration & Ergonomic Reference Sheet PDF includes clear image references and dimension callouts for every piece.

Proficient
70–89 pts

Blocks are defined and mostly purged, but base points are inconsistently placed or a few blocks are missing them; the reference sheet is present but some dimension callouts or image references are incomplete.

Developing
0–69 pts

Blocks are missing, undefined, or left unpurged. Defined base points are absent. The reference sheet is missing or lacks dimensional justification.
